NASCH Mitarbeiter-App v27.3

Neu:
- Mitarbeiter können offene Urlaub-/Wunschfrei-Anträge direkt zurückziehen.
- Bei genehmigten Urlaub-/Wunschfrei-Einträgen wird ein Rückzugsantrag gestellt; der bestehende Eintrag bleibt bis zur Admin-Genehmigung aktiv.
- Wunschfrei: "Tausch beantragen" mit neuem Datum/Zeitraum und Umfang.
- Urlaub: "Verschieben / ändern" mit neuem Zeitraum.
- Offene Änderungsanträge können vom Mitarbeiter wieder zurückgezogen werden.
- Admin erhält eine kompakte Übersicht "Rückzug / Tausch / Urlaubsänderung" mit Genehmigen/Ablehnen.
- Erst nach Admin-Genehmigung wird ein genehmigter Eintrag entfernt oder verschoben.
- Service-Worker-Cache auf v27.3 angehoben.

Hinweis: Firestore Security Rules bleiben für die echte Produktionsberechtigung maßgeblich. Clientseitige Rollen allein schützen die Datenbank nicht.
