# NASCH Sandbox V7

Diese Testversion speichert Änderungen ausschließlich lokal im Browser.

## Neu in V7
- Teilschicht bleibt im Admin-Schichteditor immer sichtbar.
- Früh/Spät werden weiterhin passend zur Tagesverfügbarkeit ausgeblendet.
- Reinigung wird nur vorgeschlagen, wenn dem Mitarbeiter die Tätigkeit `RK` zugeordnet ist.
- Bearbeitbare Tätigkeits-Legende mit Kürzel und Bezeichnung.
- `RK` ist das feste Steuerkürzel für Reinigung; die Bezeichnung kann geändert werden, das Kürzel selbst nicht.
- Die Tätigkeits-Legende wird zusätzlich unter dem normalen und dem Admin-Schichtplan angezeigt.
- Teilschicht enthält weiterhin zwei getrennte Zeitblöcke.

## Test
Admin-PIN: `1001`

Unter **Admin → Mitarbeiter & Einstellungen** kann `RK` einem Mitarbeiter zugeordnet und die Tätigkeits-Legende bearbeitet werden.
