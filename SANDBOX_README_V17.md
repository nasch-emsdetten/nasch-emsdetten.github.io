# NASCH Sandbox V17

Mitarbeiter werden aus Gründen der Nachvollziehbarkeit nicht hart gelöscht. Im Adminbereich `Mitarbeiter & Einstellungen` kann ein Mitarbeiter `Deaktiviert` und später `Reaktiviert` werden.

Deaktiviert bedeutet:
- kein Login mehr
- keine zukünftige Einsatzplanung
- keine Auswahl für neue operative Zuordnungen
- historische Stundenzettel/Daten bleiben erhalten

Der Admin selbst kann nicht deaktiviert werden.
